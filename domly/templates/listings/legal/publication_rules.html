{% translate "2. Содержание объявления" %}

{% translate "Тип сделки, тип объекта, город, цена, валюта, характеристики, состояние и существенные ограничения указываются честно. Заголовок кратко описывает объект, а описание не скрывает известные автору существенные недостатки. Запрещены поисковый спам, ложные преимущества, объявления-приманки, дубликаты и контакты, не относящиеся к объекту." %}

{% translate "3. Цена, контакты и платежи" %}

{% translate "Указывается реальная цена и правильная валюта; условная цена для привлечения внимания запрещена. Номер для связи необязателен. Указывая номер, автор подтверждает право использовать его и отдельно разрешает публичный показ в объявлении. Нельзя требовать перевод денег через описание объявления, выдавать Domly за гаранта платежа или создавать впечатление, что сервис проверил получателя." %}

{% translate "4. Фотографии и персональные данные" %}

  • {% translate "Фотографии должны относиться к объекту и соответствовать его текущему состоянию." %}
  • {% translate "Запрещены чужие изображения без разрешения, вводящие в заблуждение коллажи, водяные знаки других сервисов и незаконное содержимое." %}
  • {% translate "Нельзя публиковать паспорта, свидетельства, банковские реквизиты, переписку, лица детей и персональные данные третьих лиц без законного основания и необходимого согласия." %}
  • {% translate "Domly вправе технически уменьшать изображения, исправлять ориентацию и удалять метаданные, включая EXIF и GPS, без изменения смысла объявления." %}

{% translate "5. Адрес и карта" %}

{% translate "Город и район должны соответствовать объекту, а точка на карте — быть проверена автором. Автоматическое геокодирование может ошибаться. Если точный адрес создаёт риск для безопасности или приватности, следует указать приблизительную точку или ориентир и раскрывать детали только после проверки заинтересованного лица." %}

  • {% translate "Несуществующие объекты, мошеннические предложения, объекты без права распоряжения и сделки, нарушающие закон, обременения или права третьих лиц." %}
  • {% translate "Реклама услуг без конкретного объекта, финансовые пирамиды, сбор денег, вредоносные ссылки, спам и автоматизированный сбор данных." %}
  • {% translate "Дискриминационные условия, угрозы, оскорбления, вымогательство, незаконный или опасный контент." %}
  • {% translate "Обход проверки, повторная публикация снятого нарушения, создание новых аккаунтов для обхода ограничений и вмешательство в работу сервиса." %}
